# 史実と創作

確認日：2026-09-08。ゲーム中の事件・人物・手帳・模型・図版・影・修復票は創作。実在する古代装置や測量結果として扱わない。

- チチェン・イッツァはユカタンのマヤの都市。エル・カスティーヨ等の名称と大まかな外観のみ参考：[UNESCO](https://whc.unesco.org/en/list/483/)。画像を転用していない。
- 点1・棒5・貝形0の表現：[メキシコ教育省](https://nuevaescuelamexicana.sep.gob.mx/contenido/coleccion/los-mayas-y-su-sistema-de-numeracion/)。単一桁だけを使い、位取りや暦の精密な復元は含めない。
- 現代のマヤ文化を過去だけのものとして描かない：[Smithsonian / Living Maya Time](https://maya.nmai.si.edu/maya)。個別人物・団体・出来事の実在を示す資料ではない。
- 実装のWeb制約：[Godot Web export](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)。Compatibility / WebGL 2.0 / 単一スレッド。ブラウザー設定によって保存が制限される。

AZTEC3はユーザー指定の作品名。舞台の文化をアステカと分類する意図はなく、UIと手帳でもマヤと記載する。
