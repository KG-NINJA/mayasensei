# SHUTTER RUN — 加速する最終回廊

閉まる26枚のシャッターを避ける、オリジナルの縦スクロール脱出ゲーム。沙羅曼蛇の最終脱出場面の緊張感を参考に、素材・機体・コース・音は本作のオリジナルとして実装しています。

## テストプレイ

公開ページ: https://kg-ninja.github.io/mayasensei/shutter-run/

- 手動操縦: ← → / A D。タッチ・マウスではゲーム画面の好きな位置を左右にドラッグ。触れた位置に機体は飛ばず、指の移動量で操縦できます。Spaceで一時停止、Rで再挑戦。
- RAPIDは210 px/sから毎秒36 px/sずつ加速し、終盤は1,000 px/s超。NORMALは練習用の加速コース。
- 同じSEEDとコースでは、手動・実API・ローカル参考操縦が同じシャッター配置・速度・移動速度・当たり判定を使用。
- ブラウザーの「API接続・動作確認」内のローカル参考操縦は、画面の動作確認用。実APIとして表示・集計しません。
- 隠れたタブやフォーカスを失ったときは一時停止。再開はボタンまたはSpace。

## 実Decisions APIを接続する

Node.js 22以上。依存パッケージのインストールは不要です。既存のOpenAI APIキーをサーバー環境変数 `OPENAI_API_KEY` に設定して起動します。キーをHTML・URL・ソース・ブラウザーの保存領域に置かないでください。

```sh
# OPENAI_API_KEY が環境に設定されている状態で
node shutter-run/server.mjs
# http://127.0.0.1:4310 をブラウザーで開く
```

API自動操縦を選ぶと、サーバーから `POST https://api.openai.com/v1/decisions` に `model: gpt-6-luna` と `choice` 質問を送ります。3枚先までの各シャッターに対し5つの進路から選択。返された進路の計画を機体の操縦に使い、前のシャッターを抜けたら次のAPI選択済みの進路へ移動します。ローカルの処理は移動と当たり判定のみで、実APIモードの進路選択を代行しません。

ライブ画面には成功したAPI応答数、クライアントから見た往復判断時間、選択確率を表示。最初の判断を受信してからゲーム時計が始まり、その後のAPI待ち中もゲームは進みます。失敗時は明示して停止し、成績に記録しません。上限は毎秒3リクエスト、APIタイムアウト1.5秒、ブラウザー側1.8秒。実際のAPI利用料金がかかります。

GitHub Pagesは静的配信のためAPIキーやサーバーを持ちません。公開ページの手動モードは即プレイ可能。実APIモードには上記のサーバーでの起動、または既存のHTTPSサーバーへの配置が必要です。外部のフロントエンドを接続する場合はサーバーの `ALLOWED_ORIGIN` をそのURLのoriginに指定し、画面の接続先にサーバーURLを入力します。サーバーは標準ではlocalhostにのみバインドします。公開サーバーとして使う場合のアクセス制限・利用者別の上限・本番ホスティングはこのデモの対象外です。

## 検証

```sh
node shutter-run/tests/run.mjs
```

80コースでローカル参考操縦の完走、加速、シード再現、無入力時の接触、すり抜け防止、公式Decisionsリクエスト・応答形式を検証。モック応答はテストでのみ使用します。実APIの成績・判断時間はAPIキー接続後に実測してください。APIの優位性を事前に実測済みとは扱いません。
